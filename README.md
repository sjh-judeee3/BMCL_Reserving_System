# BMCL Reserving System

브레인앤머신 연구실(고려대학교) 공용 캘린더입니다.  
Shared lab calendar for the Brain and Machine Lab, Korea University.

🔗 **https://sjh-judeee3.github.io/BMCL_Reserving_System/**

## Features

### 1. GPU Reservations
- GPU 0–4 시간 단위 예약 (일 / 주 / 월 보기)
- 예약 1건에 GPU 1개 이상 필수
- 예약은 만든 사람만 수정·삭제 가능

### 2. Interns' Schedule
- 인턴별 색상과 열로 근무 일정 표시
- 반복 일정 지원 (매일 / 평일 / 매주 / 매월 / 매년 / 직접 설정)
- 반복 일정 삭제 시 "이 일정만" 또는 "전체" 선택 가능

## How to Use
1. 사이트에 접속해 본인 이름을 선택합니다.
2. 처음 로그인할 때 비밀번호를 설정합니다.
3. 상단 탭에서 **GPU** 또는 **Interns**를 고른 뒤, 캘린더를 클릭하거나 드래그해 일정을 추가합니다.
4. 랩내 멤버가 아니라면, guest 신분으로 view만 가능합니다.
